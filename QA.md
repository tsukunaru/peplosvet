# Проверки альфы — 05.09.2026

## Название

Выбрано «Пеплосвет: Последний кордон». Совпадений не найдено в веб-индексе и непосредственно в каталоге по запросам [Пеплосвет](https://yandex.ru/games/search?query=Пеплосвет) и [Пеплосвет: Последний кордон](https://yandex.ru/games/search?query=Пеплосвет%3A+Последний+кордон).

Дополнительно проверены запросы `site:yandex.ru/games "Пеплосвет"`, `"Пеплосвет" Яндекс Игры`, `"Пеплосвет: Последний кордон"`, `"Пеплосвет: Последний кордон" игра`. Закрытые черновики и неиндексируемые карточки неизвестны; название не зарезервировано. Английское название пока рабочее.

## Проверено автоматически

Команда `npm test`: 4 проверки, без дополнительных пакетов.

1. Экономика: сбор, оплата, создание патронов, вся цепочка из 6 заданий, оружейные ограничения по репутации, запрет повторного улучшения, переполненный рюкзак, расходники, последствия смерти, восстановление сохранения и отбрасывание повреждённых данных.
2. Связность мира: обходом карты проверены убежище, все сюжетные объекты, начальная добыча, позиция Хранителя и достаточное количество доступных изотопов.
3. Настоящий `game.js` в минимальном окружении DOM/Canvas: движение с зажатой клавишей, два начальных ящика, возврат на базу, сдача задания, создание патронов, автоогонь против мутантов. Проверены остановка симуляции в меню и при потере фокуса. Это проверка логики игрового цикла, не замена физического браузера.
4. SDK с имитацией ответов: восстановление резервной гостевой копии, выбор свежего облачного сохранения, ready/start/stop без дублирования, события паузы, выдача награды только после onRewarded, отказ/ошибка рекламы, запись сохранений.

## Проверено в браузере

- Первый запуск, игровой экран, продолжение после перезагрузки.
- Убежище и реальная покупка воды: 45 → 27 жетонов, 3 → 4 воды.
- Меню паузы и Escape; исправлено мгновенное закрытие новой паузы нативным событием cancel.
- Русский и английский интерфейсы, переключение сенсорного режима.
- Адаптивные размеры 390 × 844 и 844 × 390, отсутствие горизонтального переполнения. Проверка размеров не заменяет тест на настоящем телефоне.
- Ошибок и предупреждений консоли при проверенных действиях не обнаружено.

## Требования платформы и незавершённая проверка выпуска

Изучена официальная редакция [требований Яндекс Игр](https://yandex.ru/dev/games/doc/ru/concepts/requirements) от 18.08.2026. Основные пункты учтены архитектурно, но итоговое соответствие подтверждается только на платформе и модерации.

| Область | Реализация / оставшаяся проверка |
| --- | --- |
| [SDK](https://yandex.ru/dev/games/doc/ru/sdk/sdk-about) | `/sdk.js` загружается только на платформе, `YaGames.init()` до запуска; локальный запуск без SDK |
| [Ready / Gameplay](https://yandex.ru/dev/games/doc/ru/sdk/sdk-game-events) | Ready после удаления загрузочного экрана и открытия меню; Gameplay только во время активной игры |
| [События](https://yandex.ru/dev/games/doc/ru/sdk/sdk-events) | Независимые причины паузы для платформы, скрытой вкладки, blur и рекламы; меню сохраняет собственную паузу |
| [Сохранения](https://yandex.ru/dev/games/doc/ru/sdk/sdk-player) | Гостевой localStorage + резервная копия; облако при доступном Player; запись облака не чаще раза в 15 секунд |
| Монетизация | Добровольная реклама за аптечку; локально отключена. Реальную выдачу и SDK callbacks проверить в черновике |

| Устройства | Адаптивный интерфейс, касания, автоогонь и автосбор. На реальных Android/iOS пока не проверено |
| [Архив](https://yandex.ru/dev/games/doc/ru/console/add-new-game) | `index.html` в корне, ASCII-имена без пробелов, проверка распакованного размера ≤100 МБ |
| Карточка | Перед публикацией нужны значок, обложка, скриншоты, описание, проверка возрастной категории и заявленных устройств |
